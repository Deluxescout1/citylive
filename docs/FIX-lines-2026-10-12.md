# FIX — the fifth return of the screen stripes (2026-10-12, THE KARST, DP-3 4K@165%)

Nick: lines in the mountains AND long lines through everything in the water, LEFT screen.

## Diagnosis chain (all measured, same day)

| step | finding |
|---|---|
| live log | DP-3 (left): `dpr=2 zoom=3` (after) / was `dpr=2 zoom=2 canvas 1552x874` — the COARSE canvas |
| 4K capture | mountains band autocorrelation **+0.202 @ 60px** · water band **+0.767 @ 120px** · DP-4 control **+0.048** |
| `main.qml` | false-binary rework left `texelBuf` pinned to `pxk=3` for every screen — the 4K's fine texels (put back twice before) were gone AGAIN |
| offscreen 1:1 | karst engine output clean of resample stripes; but 13 full-depth vertical seams in the WATER were the engine's own (reflection-run hairlines + patch rims) |

## Root causes (two, independent — fixing one did not fix the other)

1. `main.qml`: two fractional resamples on 4K@165% (Qt ×1.5009 + KWin ×0.825) beat against 3-device-px
   texel blocks → stripes on every land. Fix: `texelBuf = round(dpr)` when `dpr > 1` (native texels
   on any resampled output), coarse + crop trick on integer-scale screens.
2. `city.js`: `karstSil` left 1–6px bare slivers between near-touching towers → light full-depth lines;
   the banded reflection runs' rim columns were hard alpha jumps → ruled lines. Fix: bridge slivers
   ≤8px (blend the flanks) + `bandRunRect()` feathered-run helper used by karst AND fjord.

Offscreen verification: 13 full-depth water line clusters → 1 (bezel edge). Mountains flat (+0.011).

## Rule for the future

- Stripes = RESAMPLE pipeline question, never the land. Ask: is the canvas texture mapped to the
  output by an exact integer anywhere (crop trick), or resampled fractionally (native texels)?
- Any per-run rect edge over water = a line unless feathered. `bandRunRect` exists — use it.
- The rowing crews: `sculls.test.js` guards window + rower + oar counts.
